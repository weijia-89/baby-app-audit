### Nubo

**Package:** `com.clicksie.nuboapp`  
**Version:** 1.4  
**Type:** Native Android  
**Claim:** "Local-first"  
**Static analysis:** Not performed - jadx decompilation was not completed for Nubo. The Nubo verdict rests on dynamic evidence only (see Known Limitations).

#### Dynamic Analysis

**Date:** 2026-08-03T22:03:44Z  
**Capture file:** `results/nubo-test-20260803/capture.mitm`

**Outbound connections on first launch:**

| Destination | Method | Purpose | Details |
|-------------|--------|---------|---------|
| `firebaseinstallations.googleapis.com/v1/projects/[redacted]/installations` | POST | Firebase device registration | Firebase Installation ID, JWT auth token returned |
| `firebase-settings.crashlytics.com` | GET | Crashlytics settings | Same config as Pebbi - `collect_reports`, `collect_anrs`, `sessions_enabled` |
| `android.apis.google.com/c2dm/register3` | POST | FCM push notification registration | App ID, Firebase Installation ID, device info, cert hash |
| `app-measurement.com/a` | POST | Firebase Analytics batch | Protobuf blob with session IDs, screen views (Splash, LicenseActivity, Onboarding), splash timing, route info, dwell time metrics |
| `app-measurement.com/config` | GET | Firebase Analytics config | App config with Google Analytics ID |

**Firebase analytics data captured:**
- Screen views: `Splash`, `LicenseActivity`, `Onboarding`
- Events: `startup_route_resolved` (route: onboarding), `onboarding_step_viewed` (step: delcom), `onboarding_dwell` (15s threshold)
- Performance: `in_app_splash_ms` ~503ms, `system_and_boot_ms` ~244ms, `total_launch_ms` ~747ms
- Device data: Android 9, `sdk_gphone_arm64`, `en-us` locale
- Firebase Installation ID assigned: `playerId`
- License activity from `com.clicksie.nuboapp` detected
- 10+ session batches in first 3 minutes

**data anomaly:** The `app-measurement.com` capture also contains `com.pebbi.android` data (version 4.0.1) and Pebbi's Firebase project identifier (redacted) interspersed with Nubo's data. This is unusual and warrants further investigation - possible shared library or testing residue.

#### Verdict

**FAIL.** Nubo claims "local-first" but sends extensive Firebase Analytics data on first launch, including session events, screen views, timing data, onboarding progress, and dwell time. The app registers with Firebase Installations and Crashlytics immediately. This is not local-first behavior.
